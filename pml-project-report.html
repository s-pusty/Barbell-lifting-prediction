Prediction Assignment: Exercise Performance

Peer-review project report | Prediction of barbell-lift exercise manner

1. Aim

The goal of this project is to predict how correctly a participant performed a barbell lift. The response variable is classe, with five labels: A, B, C, D, and E. The data contain measurements from accelerometers on the belt, arm, forearm, and dumbbell.

2. Data preparation

The training data contain 19,622 labelled observations. The test data contain 20 observations to be predicted. I removed row numbers, participant names, timestamps, window labels, and other administrative fields. These columns do not directly describe the movement and may allow the model to learn the recording session instead of the exercise technique.

I kept numeric sensor variables available in both files with at least 95% non-missing values. This produced 52 predictors. The selected measurements cover the belt, arm, dumbbell, and forearm. Any remaining missing values were replaced with the training median for that variable.

3. Model selection

I used a Random Forest classifier. It combines the results of many decision trees built from different samples and subsets of variables. This is useful for sensor data because the relationship between measurements and exercise type may be non-linear. Random Forest also provides variable-importance scores.

4. Validation

I used a stratified 80/20 split for training and validation. This keeps the five class proportions similar in both groups. I also used five-fold cross-validation to check the stability of the model.

Five-fold cross-validation (mean)99.64%0.36%

The five-fold accuracy had a standard deviation of about 0.08 percentage points. The close holdout and cross-validation results suggest that the model is stable for data similar to the training set.

5. Important variables and limitations

Some of the most useful measurements were belt roll, belt yaw, forearm pitch, and dumbbell magnetometer values. These measurements describe body and equipment position, so they help separate the different lifting styles.

These error estimates do not guarantee the same performance for completely new people. Rows from the same participants or recording sessions may be related. A validation study using participants who were not included in training would provide a stronger test of generalisation.

7. Conclusion

The Random Forest model predicted exercise performance with high accuracy in the validation tests. Removing identifiers and mostly empty columns helped focus the analysis on actual movement measurements. Cross-validation provided an additional check. The final predictions are saved in pml-predictions.csv.

Appendix: Reproducible analysis

See pml-project-report.Rmd for the R code that reads the two CSV files, prepares the predictors, runs the validation, fits the final Random Forest model, and writes a CSV containing the 20 predictions. Keep the R Markdown file and the two source CSV files in the same working directory before knitting it to HTML.
